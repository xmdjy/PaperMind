# 统一解析材料摘要

本轮目标：网页使用已归档 HTML 及同快照资源的原生解析；PDF 使用已部署的 Docling 服务；统一 ParsedDocument 中的正文、标题、表格、公式、图片直接提交现有 LLM API，一次生成中文图文摘要。保留原图资产、来源位置、SQLite 留档、任务去重、取消和版本保护。

HTML 不转 PDF，不抓取当前在线 URL；缺失图片保留说明。PDF 摘要解析保留全部图片、标题级别和表格结构，不影响旧 Docling 解读入口的严格图片筛选。调整现有托管隧道到用户部署的 ubuntu@101.76.222.224，端口保持 5001。

复用 document_summary_records/materials/report/task 与 assets，无数据库表迁移。解析标识纳入配置及协议版本；摘要标识纳入解析结果、提示词及模型配置（不包含密钥）。旧报告可阅读，新生成不得误用旧视觉材料。不得静默截断正文或丢弃超限图片后声称完整摘要。

本轮不做素材语义排序、章节 map/reduce、逐句证据、自动二次校对或新的模型服务。超出输入安全预算时显示明确错误。流式改造不属于打通此链路的必要条件。
