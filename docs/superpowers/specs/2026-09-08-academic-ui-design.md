# PaperMind 学术阅读界面

用户方向：参考 alphaXiv 的论文阅读、问答体验，使用棕色与米白色，沉稳、朴实，适合持续阅读。

## 设计选择

采用纸张与胡桃木的浅色工作区。与深棕侧栏相比，暖灰侧栏的明暗跳变更小；与卡片墙相比，文献目录能够完整显示更多标题和摘要。论文标题是视觉重点，不加入营销横幅或无实际作用的装饰。

| 色彩 | 值 | 用途 |
| --- | --- | --- |
| 暖纸白 | `#F7F5F0` | 工作区背景 |
| 象牙白 | `#FFFDF8` | 内容表面、输入区 |
| 亚麻色 | `#EEE9DF` | 侧栏、次级表面 |
| 墨棕 | `#352D26` | 正文、标题 |
| 胡桃棕 | `#73543C` | 主要操作、选中状态 |
| 鼠尾草绿 | `#53664D` | 已完成状态 |

标题使用 Iowan Old Style / Palatino / 宋体系统衬线字体；操作界面使用系统无衬线字体，优先本机中文字体。不依赖在线字体。正文对比度目标至少 4.5:1，主正文高于 7:1；状态同时显示文字。

## 布局

```text
文献库： [导航与正在阅读] [标题、导入操作                        ]
                          [知识库切换、搜索、状态筛选            ]
                          [论文标题、作者、摘要、标签、阅读状态  ]

阅读器： [窄导航] [返回、论文标题、阅读状态                      ]
                 [PDF 工具栏 / 原文] [论文问答 / 阅读笔记        ]
                 [                ] [来源、回答、提问输入框     ]
```

所有主要内容左对齐。桌面阅读器保留可拖动分栏，并支持键盘调整；小屏提供原文/问答切换。问答参数按需展开，避免挤占回答空间。快捷问题只填入草稿，由用户发送。

文献目录搜索标题、作者、标签和文件名，可组合阅读状态筛选与最近添加/标题排序。筛选空结果提供清除操作，初次使用提供 PDF 导入入口。保留知识库管理、PDF 选取、高亮、笔记、模型配置和本地数据接口。

## 验证

新增筛选行为测试与论文切换时异步对话的回归测试；执行完整 Vitest 与 TypeScript 检查。使用独立测试数据预览文献库、阅读问答、笔记、设置、空状态及窄屏；检查键盘操作、分栏、弹窗与文字对比度。不读取或改写用户的真实论文数据库。

## 参考

- [alphaXiv](https://www.alphaxiv.org/)：论文标题、作者、摘要的内容优先层次。
- [Radix Colors 配色组合](https://www.radix-ui.com/colors/docs/palette-composition/composing-a-palette)：中性色背景与少量强调色的角色分工。
- [WCAG 文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：普通文字至少 4.5:1。柔和背景不能以牺牲正文可读性为代价。
