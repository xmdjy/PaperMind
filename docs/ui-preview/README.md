# 学术阅读界面预览

这些截图使用独立示例数据与测试 PDF，不包含用户论文、数据库或凭据。

- [文献库](library.png)：文献目录、元数据、搜索与阅读状态筛选。
- [阅读器](reader.png)：论文原文与问答并排，包含公式和参考来源。
- [论文问答](chat.png)：跨论文选择、快捷问题与可编辑输入框。
- [设置](settings.png)：模型配置与本地数据管理。
- [手机宽度下的文献库](library-mobile.png)。
- [手机宽度下的问答](reader-discussion-mobile.png)。

浏览器验证使用本机 Vite 页面和隔离的 Chrome。问题发送连接本地测试响应，不调用真实模型服务。覆盖搜索/排序、知识库创建、PDF 缩放、键盘及鼠标分栏、划词问答、笔记编辑、抽屉焦点和小窗口视图切换。
